Project guide · Phase 0 and Phase 1

Boli बोली

A Nepali speech-to-text and text-to-speech API that runs open Nepali models on servers we control. Developers get a Sarvam-style API, playground and docs. Audio and text never go to another AI company.

What we can honestly promise in v1"Your audio is processed only by models we run ourselves. It is never sent to Sarvam, Google, OpenAI or any other AI provider. Infrastructure is currently hosted in Singapore/Mumbai; a Nepal-hosted and on-premises option is on the roadmap."

  • Plan for Phase 0 and 1 approved, decisions recorded

Read before trusting any numberThe five biggest risks

High

1. Almost no clean, large test set

NepTel is only 75 clips (about 31 minutes). Kriti trained on nearly all of FLEURS Nepali, including the test split, and on almost all of OpenSLR-54. NepTel's transcripts started as Google Chirp-2 drafts, which favours Ampixa's models.

Fix: a contamination table, 95% error ranges on every number, and our own recordings.

High

2. Licences shrink the list of models we can sell

Only Kriti V1 and its parent IndicConformer-ne are clearly commercial for speech to text, and they are really the same model. For text to speech, Matcha-Nepali (CC-BY-4.0) is the cleanest. Kala's weights are share-alike and include a Gemini-synthesised speaker.

Fix: LICENSES.md gate, a human legal read before launch, a fallback per modality.

Medium-high

3. The TypeScript serving path is unproven

sherpa-onnx has no ready Nepali speech-to-text model, and Kriti needs AI4Bharat's own NeMo fork. sherpa-onnx-node runs on CPU only. Kala needs its own Python text-to-pronunciation step.

Fix: measure CPU speed in Phase 1 (a GPU may not be needed at all), export spike with parity tests in Phase 2, Python worker as the fallback.

High

4. Real-world accuracy is about 35-40% WER

On NepTel: Kriti 40.6%, Kriti Telephony 34.5%, NepaliConformer 36.3% (its card still claims 33.8%, which the authors corrected). Kriti's famous 24.08% is on a dev set also used to pick the model.

Fix: position v1 for error-tolerant uses (search, drafts, keyword spotting) and improve with our own data in Phase 6.

Medium

5. Tooling friction on this Mac

Apple Silicon with no NVIDIA GPU, system Python 3.14, Kriti pins old library versions, NepaliConformer needs a different NeMo. This is the most likely place to get stuck and lose energy early.

Fix: one isolated uv environment per model family, so one model's libraries never break another's.

Words you will meetGlossary

WER word error rate
Substitutions + deletions + insertions, divided by the number of words in the correct transcript. 40% WER means roughly 4 in 10 words are wrong. Lower is better.
CER character error rate
The same idea counted in characters. Fairer for Devanagari, where one wrong matra makes a whole word "wrong" in WER.
Normaliser
Rules applied to both the correct text and the model output before scoring (Unicode NFC, danda, nukta, invisible joiners). It changes WER as much as the model does.
NFC Unicode normal form
The same Devanagari letter can be stored as different byte sequences. NFC picks one, so identical-looking text compares equal.
Contamination train/test leakage
A model tested on audio it trained on scores unfairly well. The reason we track which model saw which dataset.
95% error range bootstrap confidence interval
Resample the test clips many times and recompute WER to see how much the number could move. Vital for a 75-clip set like NepTel.
Sample rate
Measurements of the sound wave per second. ASR models want 16,000 (16 kHz). NepTel files are 22,050, so we convert.
Mel spectrogram
A picture of which frequencies are loud over time, on a scale that matches human hearing. This is the model's actual input.
Conformer
An encoder that mixes convolution (local sound patterns) with self-attention (longer context). Used by Kriti and NepaliConformer.
CTC
A simple decoder that labels each audio frame and merges repeats. Fast, but each frame decides on its own.
RNN-Transducer RNN-T
A decoder that also looks at the text so far. Good for streaming. Kriti uses it.
ONNX
A portable model file format. Exporting to ONNX is how a Python-trained model gets to run inside Node.
sherpa-onnx
A ready-made runtime for speech models in ONNX, with a Node package. Currently CPU-only from npm.
Parity test
Run the Python model and the exported ONNX model on the same clips and check the transcripts match.
VITS
A text-to-speech model that goes from text all the way to a waveform in one network. Kala and Piper use it.
G2P grapheme to phoneme
Turns written text into pronunciation symbols before speech is generated. Kala has its own Nepali G2P.
Real-time factor RTF
Processing time divided by audio length. 0.1 means 10 seconds of audio takes 1 second to process.
Code-mixing
Mixing Nepali and English in one sentence. It is how most people talk, so the test set must include it.
uv and virtual environment
uv is Python's pnpm. A virtual environment (.venv) is the project's private set of packages, like node_modules.
dataclass
A typed Python record, like a TypeScript interface that also builds the object for you.
Test-driven development
Write the test first, watch it fail (red), then write the code until it passes (green).
CC-BY-NC / CC-BY-SA
NC: non-commercial use only. SA: share-alike, so anything you build from it must use the same licence.
