How a part works
  1. Start your recorder (Voice Memos, QuickTime or any phone recorder). No noise reduction.
  2. For each sentence, say the number shown in red, pause, then read the sentence naturally.
  3. Press Space or Done to move on. Stumbled? Say the number and read it again.
  4. Press F to flag a sentence that sounds unnatural, with a suggested fix.
  5. Stop the recorder after the last sentence. Save it with the name above into ml/eval/datasets/own/raw/.
