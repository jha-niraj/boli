**Kura** (कुरा, conversation) is where you talk to Boli's model. Write in Romanized Nepali, English, Devanagari or a mix, and it answers the way you wrote. Turn thinking on for harder questions, adjust the settings, copy the same request as code in five languages, and come back to saved chats. Each reply shows what it cost.
