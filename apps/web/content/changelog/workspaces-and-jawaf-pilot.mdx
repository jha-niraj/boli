Every account is now a workspace. Credits, API keys and Kura chats belong to the workspace, and you can invite people to it as members and choose which products each of them can use. If you belong to more than one workspace, switch between them in the app.

Jawaf is in pilot with a small group of businesses. It answers a business's customers from its own website, files and facts, in Nepali, Romanized Nepali or English, through a public link and a QR poster. It runs on the same open model as Kura. When it does not know, it says so and takes a phone number instead of guessing. A chat bubble for websites and API access come next. Want it for your business?
